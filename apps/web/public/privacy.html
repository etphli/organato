Organato privacy

Organato is a private personal application. It reads upcoming Canvas assignments, manages events only in a dedicated app-created Google Calendar, and uses Gmail send permission only to deliver the owner’s reminder digest.

Private data is stored in the owner’s configured Cloudflare D1 database. Provider credentials are encrypted server-side. Organato does not sell data, use advertising, run third-party analytics, or use private content for AI training.

The owner can export, archive, restore, or permanently delete data from Settings. Google access can be revoked from the Google Account permissions page; Canvas access can be revoked by deleting the personal token in Canvas.
